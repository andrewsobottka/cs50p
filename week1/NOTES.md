## Warnings

This lesson uses match / case syntax, which requires python3.10 or later. Make sure to check which python is installed; default that shipped with macOS in 2026 was still 3.9.

## Symbols & Keywords Learned

- `>` : greater than
- `<` : less than
- `>=` : greater than or equal to
- `<=` : less than or equal to
- `==` : equal to
- `!=` : not equal to

- `if`, `elif`, `else` : executes code if select condition is true
   - `or` : executes if any of the listed conditions are true
   - `and` : executes if all of the listed conditions are true

- `match` and `case` : can be used in cases where you have many elif conditions
